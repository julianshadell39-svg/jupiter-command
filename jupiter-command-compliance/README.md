# Jupiter Command Compliance

This directory contains all compliance-related documentation, policies, and evidence artifacts for the Jupiter Command platform.

## Structure

| Directory | Purpose |
|---|---|
| `policies/` | Organizational security and usage policies |
| `soc2/` | SOC 2 Type II trust service criteria and control mapping |
| `audit/` | Audit log templates and scheduled review records |
| `risk-register/` | Risk identification, scoring, and treatment tracking |
| `incident-response/` | Incident response plan and post-mortem templates |
| `access-control/` | Access control policy and user access review records |
| `evidence/` | Evidence collection guides and artifacts for audits |
| `security-monitoring/` | Security monitoring runbooks and alert definitions |

## Ownership

- **Compliance Owner:** Jupiter Command Security Team
- **Contact:** support@howtogiveback.org
- **Review Cadence:** Quarterly (policies), Annually (SOC 2 audit)

## Quick Reference

- All policies must be reviewed and re-approved at least annually.
- Risk register entries must be reviewed quarterly.
- Incident response plan must be tested via tabletop exercise at least once per year.
- Evidence artifacts for the current audit period are stored in `evidence/`.
