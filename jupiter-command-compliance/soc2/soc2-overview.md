# SOC 2 Trust Service Criteria – Overview

**Version:** 1.0  
**Effective Date:** 2026-07-04  
**Owner:** Jupiter Command Security Team

## Scope

Jupiter Command pursues SOC 2 Type II certification covering the following Trust Service Categories:

- **Security (CC)** – Required
- **Availability (A)** – In scope
- **Confidentiality (C)** – In scope

Processing Integrity and Privacy are out of scope for the current audit period.
